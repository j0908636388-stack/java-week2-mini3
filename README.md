# Java 第二週 - 小型專案 3 : TinyCompiler
問題1:
      在執行完第一個加法指令 ADD R0, R1, R2 之後，R1與R2的相加結果已經成功計算並儲存在暫存器 R0 中。
此時 R2 原本存放的第二個數字已經完成計算使命，後續流程不再需要使用到該舊值。因此，第二次直接將第三個數字載入並覆蓋 R2（MOVI R2, third），再執行 ADD R0, R0, R2，可以有效節省暫存器的使用數量，且完全不會影響最終計算結果。
問題2:
     目前程式是使用 Scanner.next() 與 Scanner.nextInt() 來逐一讀取語法單詞（Token）。
Java 的 Scanner 預設是以**空白**作為分隔符號,當輸入為 int result=7+3+1; 時（中間沒有任何空格），Scanner 會把 result=7+3+1; 整個看成一整串連續的字串。當程式執行到 nextInt() 準備讀取整數時，會因為無法將整串包含等號與加號的字串 result=7+3+1; 解析為單一整數,進而引發錯誤。
